## 一、PERCENT 折扣券抵扣为 0

### 问题描述

用户有一张 PERCENT 券「新人7折卷」（coupon_id=185, type=PERCENT, value=30，表示减免 30%），订单金额 10150 铢（生鲜 10000 + 朗姆酒 150）。选择该券后，后端 preview 返回 coupon_discount=0，实际应该抵扣 3045 铢。

### 复现步骤

1. 用户有 3 张券（后端 /coupons/available 返回）：

```json
[
  {"id":185, "type":"PERCENT", "value":30, "name":"新人7折卷"},
  {"id":52,  "type":"FIXED",  "value":3,  "name":"30-3优惠卷", "min_spend":30},
  {"id":184, "type":"ITEM",   "value":1,  "name":"菜品任选卷"}
]
```

2. 购物车有 2 个商品：
   - 生鲜（id=256, price=10000, exclude_from_discount=false）
   - 朗姆酒（id=263, price=150, exclude_from_discount=true）

3. 订单总金额 10150 铢

4. 调 POST /api/v1/orders/preview，请求体：

```json
{
  "store_id": 55,
  "items": [
    {"menu_item_id": 256, "quantity": 1, "unit_price": 10000, "specs": {}},
    {"menu_item_id": 263, "quantity": 1, "unit_price": 150, "specs": {}}
  ],
  "order_type": "DINE_IN",
  "coupon_id": 185
}
```

5. 响应：

```json
{
  "coupon_discount": 0,
  "campaign_discount": 0,
  "discount_eligible": true,
  "total_amount": 10150
}
```

### 预期行为

- coupon_discount 应为 3045（10150 x 30%）
- 或者如果 PERCENT 券只作用于非排除分类商品，应为 3000（10000 x 30%）
- total_amount 应为 7105（或 7150）

### 实际行为

- coupon_discount = 0（未抵扣）
- total_amount = 10150（原价）

### 疑问

1. PERCENT 券的 value=30 是否表示"减免 30%"？如果是，为什么 coupon_discount=0？
2. 混合订单（含 exclude_from_discount 商品）时，PERCENT 券是否只作用于非排除分类商品？如果是，应该按 10000 x 30% = 3000 抵扣，而不是 0。
3. 是否存在"有活动折扣时 PERCENT 券不可叠加"的规则？但 campaign_discount=0（没有活动折扣），所以应该不存在防折上折的问题。

### 测试账号

- 用户：user 120
- 门店：store 55
- 券：id 185（PERCENT, value=30）

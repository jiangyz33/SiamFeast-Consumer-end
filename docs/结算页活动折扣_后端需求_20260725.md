## 一、问题现象

当前结算页(`pages/checkout/index.vue`)的总价计算**不包含活动折扣**:

```
当前结算页显示:
  商品总价: ฿200.00
  优惠券:   -฿30.00
  金币抵扣: -฿10.00
  总计:     ฿160.00    ← ❌ 没扣"特殊日期 9 折 -฿20.00"

后端实际创建订单:
  subtotal:        200
  discount_amount:  20    (活动折扣)
  coupon_discount:  30
  coin_deduct:     10
  total_amount:    140    ← 实际支付金额
```

**用户看到 ¥160,但实际扣 ¥140**,中间差了 ¥20 的活动折扣。

---

## 二、前端期望的解决方案

### 方案 A:新增结算预计算接口(推荐)⭐

```
POST /api/v1/orders/preview
Authorization: Bearer <access_token>
Content-Type: application/json
```

**请求体**(和创建订单一样,但不真正下单):
```json
{
  "store_id": 55,
  "order_type": "DINE_IN",
  "items": [
    { "item_id": 1, "quantity": 2, "specs": {} }
  ],
  "coupon_id": 12,
  "coins_to_use": 50,
  "table_number": "A1"
}
```

**响应**:
```json
{
  "code": 0,
  "data": {
    "subtotal": 200.00,
    "campaign_discount": 20.00,
    "campaign_name": "双号日全场9折",
    "campaign_name_en": "Double Day 10% Off",
    "campaign_name_th": "วันตัวเลขซ้ำ ลด 10%",
    "coupon_discount": 30.00,
    "coin_deduct": 10.00,
    "coins_used": 50,
    "total_amount": 140.00,
    "new_product_bonus_points": 20,
    "extra_points": 50,
    "extra_coins": 5
  }
}
```

**字段说明**:

| 字段 | 类型 | 说明 |
|---|---|---|
| `subtotal` | number | 商品原价小计 |
| `campaign_discount` | number | 活动折扣金额(DISCOUNT/FULL_REDUCTION/SPECIAL_DATE) |
| `campaign_name` | string | 活动名称(中文) |
| `campaign_name_en` | string | 活动名称(英文) |
| `campaign_name_th` | string | 活动名称(泰文) |
| `coupon_discount` | number | 优惠券抵扣金额 |
| `coin_deduct` | number | 金币抵扣金额 |
| `coins_used` | number | 实际消耗金币数 |
| `total_amount` | number | **最终支付金额**(所有折扣后) |
| `new_product_bonus_points` | number | 新品额外积分(展示用,购买后发放) |
| `extra_points` | number | 特殊日期额外积分(展示用) |
| `extra_coins` | number | 特殊日期额外金币(展示用) |

### 前端调用时机

1. **进入结算页** → 调 `preview` → 显示完整价格明细
2. **用户选/换优惠券** → 重新调 `preview`
3. **用户开/关金币抵扣** → 重新调 `preview`
4. **用户点"提交订单"** → 调 `createOrder`(用 preview 返回的 total_amount)

## 九、总结

**核心问题**:当前前端结算页**不知道有活动折扣**,导致显示的金额和实际扣款不一致。

**解决方案**:后端加 `POST /orders/preview` 预计算接口,返回所有折扣明细。前端调用后显示完整价格。

**工作量**:
- 后端:**4-6h**(preview 接口 + 创建订单/详情返回明细)
- 前端:**2-3h**(结算页 + 订单详情改显示)

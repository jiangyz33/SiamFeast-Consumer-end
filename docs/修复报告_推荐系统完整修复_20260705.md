# 修复报告 — 总控端推荐奖励单位错乱 + 统计数据修正

> 日期：2026-07-05

---

## 1. 总控端奖励记录缺少 reward_unit（P1）

### 问题
总控端 `/admin/referral-rewards` 接口的 `ReferralRewardEnriched` struct 和 `ListRewardsEnriched` SQL 都没有 `reward_unit` 字段。前端拿不到真实单位，被迫按 `reward_type` 猜测，把 ORDER_COMMISSION（实际是积分）显示成了金币。

### 修复

| 文件 | 改动 |
|------|------|
| `model/referral.go` | `ReferralRewardEnriched` 加 `Unit string json:"unit"` |
| `marketing/repository.go` | `ListRewardsEnriched` SQL 加 `rw.reward_unit`，Scan 加 `&rw.Unit` |

### 验证
```
ORDER_COMMISSION  200  unit=POINT  ✅
ORDER_COMMISSION    8  unit=POINT  ✅
FIRST_ORDER       100  unit=COIN   ✅
```

---

## 2. 累计金币统计把积分算进去（P0）

### 问题
`total_coins_earned` = 416（错误），把积分返佣也加进了金币统计。

实际应为：金币 200（50+50+100），积分 216（200+8+8）。

### 修复

| 文件 | 改动 |
|------|------|
| `marketing/repository.go` | `GetTotalCoinsEarned` SQL 加 `AND reward_unit = 'COIN'` |
| `marketing/service.go` | `grantOrderCommissionInTx` 删除 `UpdateStats` 调用（积分不计入金币累计） |
| DB | `referrals.total_coins_earned` 按 COIN 重新回填 |

### 验证
```
改前：total_coins_earned = 416 ❌
改后：total_coins_earned = 200 ✅
```

---

## 3. remark 中文硬编码 → 翻译 key（P1）

### 修复
| 改前（中文） | 改后（key） |
|-------------|------------|
| 推荐新用户注册奖励 | `SIGN_UP` |
| 被推荐人首单奖励 | `FIRST_ORDER` |
| 消费返利 | `ORDER_COMMISSION` |

`coin_transactions` 和 `point_transactions` 的 remark 同步修复。历史数据批量 UPDATE。

前端按 key 映射三语：
```
SIGN_UP → 注册奖励 / Sign-up Bonus / รางวัลสมัครสมาชิก
FIRST_ORDER → 首单奖励 / First Order Bonus / รางวัลคำสั่งซื้อแรก
ORDER_COMMISSION → 消费返利 / Commission / คอมมิชชัน
```

## 4. 首单双倍返利关闭

```go
// 改前
firstOrderCoins := inviteCoins * 2    // 100

// 改后
firstOrderCoins := inviteCoins        // 50
```

---

## 5. 积分订单商品名 omitempty

`MallOrder.ProductNameEn/Th` 去掉 `omitempty`，空值也返回。

---

## 6. 被邀请人列表缺少用户信息

`ListByReferrer` SQL JOIN users 表，返回 `referee_nickname` / `referee_avatar`。

---

## 7. 优惠券 FULL_REDUCTION 类型漏算

`calculateCouponDiscount` switch 加 `"FULL_REDUCTION"` case。

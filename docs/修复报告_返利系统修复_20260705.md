## 1. 返佣积分/金币混淆（P0）

### 问题
ORDER_COMMISSION（消费返佣）实际发的是**积分**（GrantPoints），但 `referral_rewards` 表没有 `reward_unit` 字段区分金币和积分。C端把积分返佣显示成了金币。

### 修复

#### 数据库
```sql
ALTER TABLE referral_rewards ADD COLUMN reward_unit VARCHAR(10) DEFAULT 'COIN';
```

#### 代码
| 文件 | 改动 |
|------|------|
| `model/referral.go` | ReferralReward 加 `RewardUnit string json:"reward_unit"` |
| `marketing/service.go` | SIGN_UP/FIRST_ORDER 设 `RewardUnit: "COIN"`；ORDER_COMMISSION 设 `RewardUnit: "POINT"` |
| `marketing/repository.go` | INSERT/SELECT/Scan 全部加 reward_unit |

#### 数据回填
```sql
UPDATE referral_rewards SET reward_unit = 'POINT' WHERE reward_type = 'ORDER_COMMISSION';
UPDATE referral_rewards SET reward_unit = 'COIN' WHERE reward_type IN ('SIGN_UP', 'FIRST_ORDER');
```

### 验证结果
```
SIGN_UP          50   COIN   ✅
SIGN_UP          50   COIN   ✅
FIRST_ORDER     100   COIN   ✅
ORDER_COMMISSION 200  POINT  ✅
ORDER_COMMISSION   8  POINT  ✅
ORDER_COMMISSION   8  POINT  ✅
```

## 3. remark 中文硬编码 → 翻译 key（P1）

### 问题
返利记录的 `remark` 字段是中文硬编码（"推荐新用户注册奖励"、"被推荐人首单奖励"、"消费返利"），C端泰文界面显示乱码。

### 修复
remark 改为翻译 key，前端按 key 映射三语：

| 改前（中文） | 改后（key） |
|-------------|------------|
| 推荐新用户注册奖励 | `SIGN_UP` |
| 被推荐人首单奖励 | `FIRST_ORDER` |
| 消费返利 | `ORDER_COMMISSION` |

同步修复了 `coin_transactions` 和 `point_transactions` 表的 remark（中文 → key）。

历史数据已批量 UPDATE。

## 5. 积分订单商品名 omitempty 导致空值不返回（P1）

### 问题
`MallOrder.ProductNameEn` / `ProductNameTh` 的 JSON tag 带 `omitempty`，当值为空字符串时字段从 JSON 中消失，C端 fallback 失败。

### 修复
`model/mall.go`：去掉 `omitempty`
```go
ProductNameEn string `json:"product_name_en"`   // 原: json:"product_name_en,omitempty"
ProductNameTh string `json:"product_name_th"`   // 原: json:"product_name_th,omitempty"
```

## 6. 优惠券 FULL_REDUCTION 类型折扣未计算（P0）

`calculateCouponDiscount` 的 switch 只处理 `PERCENT` 和 `FIXED`，漏了 `FULL_REDUCTION`（满减），导致满减券折扣算出来是 0。

### 修复
```go
// 改前
case "FIXED":

// 改后
case "FIXED", "FULL_REDUCTION":
```

# 堂食/外卖互斥状态 接口说明文档

> 更新时间：2026-05-19 | Commit: da8a458

---

## 一、概述

餐饮店通过 `delivery_enabled` 字段区分为**堂食店**和**外卖店**，两种状态互斥：

| delivery_enabled | 店铺类型 | 说明 |
|------------------|----------|------|
| `false`（默认） | 堂食店 | 仅支持到店消费 |
| `true` | 外卖店 | 支持配送，需配置配送范围 |

**权限规则：**
- 只有总控端（super_admin）可以设置/修改门店的配送状态
- 门店端（store_admin/cashier）**不可**自行切换

---

## 二、接口变更

### 1. 创建门店

```
POST /api/v1/admin/stores
Authorization: Bearer <super_admin_token>
```

**新增字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `delivery_enabled` | bool | 否 | 是否为外卖店，默认 `false`（堂食店） |
| `delivery_radius_m` | int | 否 | 配送范围（米），外卖店建议必填 |

**请求示例（创建外卖店）：**
```json
{
  "name": "测试外卖店",
  "code": "DEL001",
  "business_types": ["SEAFOOD_NOODLE"],
  "delivery_enabled": true,
  "delivery_radius_m": 5000,
  "latitude": 13.7563,
  "longitude": 100.5018,
  "admin_username": "admin",
  "admin_password": "123456"
}
```

**请求示例（创建堂食店）：**
```json
{
  "name": "测试堂食店",
  "code": "DINE001",
  "business_types": ["SEAFOOD_NOODLE"],
  "delivery_enabled": false,
  "admin_username": "admin",
  "admin_password": "123456"
}
```

---

### 2. 更新门店配送状态

```
PATCH /api/v1/admin/stores/:id
Authorization: Bearer <super_admin_token>
```

**可用字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `delivery_enabled` | bool | 切换堂食/外卖 |
| `delivery_radius_m` | int | 配送范围（米） |

**请求示例（堂食店切换为外卖店）：**
```json
{
  "delivery_enabled": true,
  "delivery_radius_m": 3000
}
```

---

### 3. 总控端门店列表（增加筛选）

```
GET /api/v1/admin/stores
Authorization: Bearer <super_admin_token>
```

**新增查询参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `delivery_enabled` | string | `true` 只看外卖店，`false` 只看堂食店，不传返回全部 |

**请求示例：**
```
GET /api/v1/admin/stores?delivery_enabled=true        → 只看外卖店
GET /api/v1/admin/stores?delivery_enabled=false       → 只看堂食店
GET /api/v1/admin/stores?keyword=测试&status=OPEN      → 不限类型
```

**响应示例：**
```json
{
  "items": [
    {
      "id": 1,
      "name": "测试外卖店",
      "delivery_enabled": true,
      "delivery_radius_m": 5000,
      "status": "OPEN",
      "business_types": ["SEAFOOD_NOODLE"]
    }
  ],
  "total": 1,
  "page": 1,
  "page_size": 20
}
```

---

### 4. C端门店列表（增加定位过滤）

```
GET /api/v1/public/stores
```

**新增查询参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `latitude` | float | 否 | 用户当前纬度 |
| `longitude` | float | 否 | 用户当前经度 |

**过滤逻辑：**

| 门店类型 | 是否传定位 | 行为 |
|----------|-----------|------|
| 堂食店 | 传/不传 | 正常返回，按距离排序 |
| 外卖店 | 传定位 | 计算用户到门店距离，**超出配送范围的不返回** |
| 外卖店 | 不传定位 | 正常返回（不过滤） |

**请求示例：**
```
GET /api/v1/public/stores?latitude=13.75&longitude=100.50
GET /api/v1/public/stores?keyword=海鲜面&page=1&page_size=10
```

**响应示例：**
```json
{
  "items": [
    {
      "id": 1,
      "name": "附近堂食店A",
      "delivery_enabled": false,
      "delivery_radius_m": 0,
      "status": "OPEN",
      "business_types": ["SEAFOOD_NOODLE"],
      "logo_url": "...",
      "business_hours": "09:00-22:00"
    },
    {
      "id": 5,
      "name": "可配送的外卖店B",
      "delivery_enabled": true,
      "delivery_radius_m": 5000,
      "status": "OPEN"
    }
  ],
  "total": 2,
  "page": 1,
  "page_size": 20
}
```

> 注意：外卖店"不可配送的店C"因为距离超出 5000m，不会出现在列表中。

---

### 5. 门店端更新配置（已禁用 delivery_enabled）

```
PATCH /api/v1/store-config
Authorization: Bearer <store_admin_token>
```

**`delivery_enabled` 已从可修改字段中移除。** 即使传入也会被忽略。

**仍可修改的字段：**
- `address`, `phone`, `latitude`, `longitude`
- `formatted_address`, `place_id`, `delivery_radius_m`
- `opening_time`, `closing_time`, `delivery_fee`, `min_order_amount`
- `preparation_min`, `auto_accept_orders`, `notifications`
- `logo_url`, `background_image_url`, `images`

## 三、业务流程

```
总控端创建门店
  │
  ├─ delivery_enabled=false（或不传）→ 堂食店
  │   └─ delivery capability = false
  │
  └─ delivery_enabled=true → 外卖店
      ├─ delivery capability = true
      └─ delivery_radius_m 需配置

总控端随时可切换：
  PATCH /admin/stores/:id  { "delivery_enabled": true/false }

门店端：
  ✗ 无法修改 delivery_enabled

C端用户：
  定位后请求门店列表 → 堂食店全部返回 + 外卖店按配送范围过滤
```

## 四、数据库字段参考

**stores 表：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `delivery_enabled` | boolean | `false`=堂食店，`true`=外卖店 |
| `delivery_radius_m` | int | 配送范围（米），外卖店使用 |

**store_capabilities 表：**

| capability | 堂食店 | 外卖店 |
|------------|--------|--------|
| `delivery` | false | true |
| `menu_edit` | true | true |
| `campaign_create` | true | true |

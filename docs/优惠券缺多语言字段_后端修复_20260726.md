# 优惠券列表缺少多语言字段 - 后端修复需求

> 日期：2026-07-26
> 收件人：后端
> 发件人：前端 jiangyz33
> 优先级：P1
> 影响范围：C 端所有显示优惠券的页面

---

## 一、问题现象

C 端切换到泰文/英文后，优惠券名称**仍然显示中文**：

| 语言 | 期望显示 | 实际显示 |
|---|---|---|
| 中文 | 无门槛-10 | ✅ 无门槛-10 |
| 英文 | No Min -10 | ❌ 无门槛-10 |
| 泰文 | ไม่จำกัดขั้นต่ำ -10 | ❌ 无门槛-10 |

---

## 二、根因

后端 `GET /api/v1/coupons` 返回的 items 里**只有 `name`（中文），没有 `name_en` / `name_th`**。

### 当前返回（实测 2026-07-26）

```json
{
  "items": [
    {
      "id": 35,
      "coupon_id": 19,
      "name": "无门槛-10",
      "type": "FIXED",
      "value": 10,
      "min_spend": 0,
      "status": "LOCKED"
    },
    {
      "id": 32,
      "coupon_id": 11,
      "name": "30-3优惠卷",
      "type": "FIXED",
      "value": 3,
      "min_spend": 30,
      "status": "ACTIVE"
    }
  ]
}
```

**缺少**：`name_en` / `name_th` / `description_en` / `description_th`

## 三、期望返回格式

### 方案 A：平铺多语言字段（推荐）

```json
{
  "items": [
    {
      "id": 35,
      "coupon_id": 19,
      "name": "无门槛-10",
      "name_en": "No Min -10",
      "name_th": "ไม่จำกัดขั้นต่ำ -10",

      "value": 10,
      "min_spend": 0,
      "status": "LOCKED"
    }
  ]
}
```

### 方案 B：内嵌 template 子对象

```json
{
  "items": [
    {
      "id": 35,
      "coupon_id": 19,
      "name": "无门槛-10",
      "type": "FIXED",
      "value": 10,
      "min_spend": 0,
      "status": "LOCKED",
      "template": {
        "name": "无门槛-10",
        "name_en": "No Min -10",
        "name_th": "ไม่จำกัดขั้นต่ำ -10"
      }
    }
  ]
}
```

**前端两种方案都支持**（代码已有 `tpl['name_' + lang]` 和 `c['name_' + lang]` 两种取值）。

## 七、数据库确认

优惠券模板表 `coupons` 应该已有 `name` / `name_en` / `name_th` 字段（admin 创建时填的）。问题是 **user_coupons 关联查询时没 SELECT 这几列**。

### 后端排查

```sql
-- 查看 coupon 模板有没有多语言字段
SELECT id, name, name_en, name_th FROM coupons WHERE id IN (11, 19);

-- 查看 user_coupons 关联查询
SELECT uc.id, uc.coupon_id, c.name, c.name_en, c.name_th
FROM user_coupons uc
LEFT JOIN coupons c ON uc.coupon_id = c.id
WHERE uc.user_id = 105;
```

### 可能的修复

```sql
-- repository 的 SELECT 需加 JOIN
SELECT uc.*, c.name, c.name_en, c.name_th, c.type, c.value, ...
FROM user_coupons uc
LEFT JOIN coupons c ON uc.coupon_id = c.id
WHERE uc.user_id = $1
```

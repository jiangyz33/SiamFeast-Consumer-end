## 登录方式

### 手机号 + 密码

```
POST /api/v1/auth/login
Content-Type: application/json

{
  "phone": "+66999100001",
  "password": "123456"
}
```

返回的 `access_token` 即为 JWT，后续请求加 `Authorization: Bearer <token>`。

> 这些账号 `provider='phone'`、`password_hash` 已入库，可直接走密码登录通道，**不需要短信验证码**。

### JWT 直签（测试/调试用）

如需绕过登录接口，可直接签 JWT：

```bash
# SF_JWT_SECRET 来自服务器 .env.docker
HMAC-SHA256，payload: {"sub": "<user_id>", "role": "consumer", "iat": ..., "exp": ...}
```

注意：`role` 必须**小写** `"consumer"`，大写会触发 `403 PERMISSION_DENIED`。

SELECT u.id, u.phone, u.nickname, u.invite_code, u.email,
       mp.membership_tier, mp.coin_balance, mp.point_balance

## 创建过程

### 1. 创建账号

1. 生成 bcrypt hash：在 `docker run golang:1.25-alpine` 容器内调用 `bcrypt.GenerateFromPassword("123456", bcrypt.DefaultCost)`
2. 生成 5 个随机 8 字符邀请码（避免与现有冲突）
3. 写入 `tmp/seed_test_users.sql`，通过 `psql <` 执行
4. 验证 `users` + `member_profiles` 两表数据一致

SQL 文件留存：`tmp/seed_test_users.sql`（可重复执行，`member_profiles` 有 `ON CONFLICT DO NOTHING`）。

### 2. 补发新人礼包（创建当天，2026-08-02）

**原因**：步骤 1 是直接 SQL INSERT，绕过了注册接口 `SMSLogin()`，没触发 `marketing.ReferralService.IssueNewUserGift()`。

**方式 A（采用）**：写一次性 Go 程序 `cmd/grant_gift/main.go`，在 `golang:1.25-alpine` 容器内编译运行，调用完整业务路径：

```bash
sudo docker run --rm \
  --network siamfeast-api-go_default \
  -v /www/wwwroot/siamfeast-api-go:/app \
  -w /app \
  --env-file /www/wwwroot/siamfeast-api-go/.env.docker \
  golang:1.25-alpine \
  sh -c 'go build -o /tmp/grant_gift ./cmd/grant_gift && /tmp/grant_gift 206 207 208 209 210'
```

**业务路径**：`ReferralService.IssueNewUserGift` → `GetNewUserGiftConfig` → `ClaimNewUserGift`（同事务防重）→ `GrantNewUserGiftCoupons`（22 张/人）→ `GrantCoins`（配置 `coin_amount=0` 跳过）

**结果**：5 个账号 `new_user_gift_claimed=true`，每人 22 张 ACTIVE 券，0 金币（符合配置）。

**清理**：补发完成后删除了 `cmd/grant_gift/main.go`（一次性工具，不入版本控制）。如需再次运行，可参考本文档重新创建。

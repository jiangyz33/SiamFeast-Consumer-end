## 三、需求 1:积分商城兑换通知门店

### 3.1 业务流程

```
用户进积分商城 → 选商品
   ↓
选择兑换(进入结算)
   ↓
【新增】选门店(下拉/弹窗选择就近门店)
   ↓
【新增】选提货时间(必须 > 当前时间 + 24h)
   ↓
填收件人姓名/电话(已有)
   ↓
提交兑换 → POST /mall/products/:id/redeem
   ↓
后端创建 mall_order + 通知门店 staff
   ↓
用户看兑换状态(待配货 / 已配货)
```

## 五、需求 3:邀请延迟返利

### 5.1 业务流程

```
A 邀请 B → B 注册绑定邀请码
   ↓
A 的邀请奖励 status = PENDING(不发积分)
   ↓
B 首单支付成功
   ↓
A 的奖励 status = GRANTED(发积分)
   ↓
若 B 注册后 N 天未消费
   ↓
A 的奖励 status = ROLLED_BACK(回滚)
```

### 5.2 C 端改动清单

| 文件 | 改动 | 工时 |
|---|---|---|
| `pages/referral/index.vue` | 推荐记录显示状态徽章(PENDING/GRANTED/ROLLED_BACK) | 0.5h |
| `pages/referral/index.vue` | 文案改:"邀请好友消费后,你将获得积分"(原"邀请即得积分") | 0.2h |
| `i18n/index.js` | 加 3 个状态文案 | 0.3h |

### 5.3 接口契约(等后端确认)

**修改** `GET /api/v1/referrals` 返回字段:

```json
{
  "items": [
    {
      "id": 1,
      "invitee_phone": "+66812345678",
      "invitee_nickname": "用户 abc",
      "status": "PENDING",       // PENDING / GRANTED / ROLLED_BACK
      "reward_amount": 11,
      "reward_type": "POINT",
      "invited_at": "2026-07-23T10:00:00Z",
      "granted_at": null
    }
  ]
}
```

### 5.4 状态文案(中英泰)

| 状态 | 中文 | 英文 | 泰文 |
|---|---|---|---|
| PENDING | 待发放(好友消费后到账) | Pending (grants after friend's first order) | รอดำเนินการ (ได้รับหลังเพื่อนสั่งซื้อ) |
| GRANTED | 已发放 | Granted | อนุมัติแล้ว |
| ROLLED_BACK | 已过期(好友未消费) | Expired (friend didn't order) | หมดอายุ (เพื่อนยังไม่สั่งซื้อ) |

## 七、需求 5:金币换积分 + 新人礼包

### 7.1 业务流程

```
用户进个人中心 → 点"金币换积分"
   ↓
GET /coins/exchange-config → 拿兑换比例(如 10 金币 = 1 积分)
   ↓
显示当前金币 + 积分余额
   ↓
用户输入要兑换的金币数
   ↓
实时计算可得积分数
   ↓
确认兑换 → POST /coins/convert-points
   ↓
扣金币 + 加积分 + 刷新余额
```

### 7.2 C 端改动清单

| 文件 | 改动 | 工时 |
|---|---|---|
| **新建** `pages/exchange/index.vue` | 兑换页 UI + 实时计算 + 确认弹窗 | 1.5-2h |
| `pages/member/index.vue` | 加"金币换积分"入口 | 0.2h |
| `api/services/member.js` | 加 `convertCoinsToPoints()` + `getExchangeConfig()` | 0.3h |
| `pages.json` | 注册 `/pages/exchange/index` 路由 | 0.1h |
| `i18n/index.js` | 兑换文案 | 0.3h |

### 7.3 接口契约(工单已确定)

**兑换** `POST /api/v1/coins/convert-points`:

```json
// 请求
{ "coins_to_spend": 100 }

// 响应
{
  "code": 0,
  "data": {
    "coins_spent": 100,
    "points_received": 10,
    "coin_balance_after": 50,
    "point_balance_after": 120
  }
}
```

**错误码**:
| code | 文案 |
|---|---|
| `INVALID_AMOUNT` | 兑换数量太少(低于最小限制)|
| `INSUFFICIENT_COINS` | 金币余额不足 |
| `DAILY_LIMIT_EXCEEDED` | 今日已达兑换上限 |
| `EXCHANGE_DISABLED` | 兑换功能未开放 |

**配置**(展示用) `GET /api/v1/coins/exchange-config`:
```json
{
  "code": 0,
  "data": {
    "coins_per_point": 10,
    "min_coins_per_exchange": 10,
    "max_points_per_day": 0,
    "is_enabled": true
  }
}
```

## 二、前端实际发送的字段(⭐ 重要)

HBuilderX 内置 Google OAuth 模块**返回的不是标准 id_token**,而是国内简化版的 `openid` + `unionid`:

```json
{
  "id_token": "",
  "access_token": "",
  "openid": "117753119525355488475",
  "unionid": "117753119525355488475"
}
```

⚠️ **`id_token` 和 `access_token` 都是空字符串**,只有 `openid` 和 `unionid` 有值。

这是 HBuilderX 标准 OAuth 模块的设计,跟后端文档中"标准 OAuth 2.0 id_token 流程"不同。

请后端确认接口处理逻辑:

```go
// 推荐处理顺序
if req.IDToken != "" {
    // 优先级 1:标准 OAuth,验证 id_token 签名
    payload := verifyIDToken(req.IDToken)
    uid = payload.Sub
    email = payload.Email
    name = payload.Name
} else if req.AccessToken != "" {
    // 优先级 2:用 access_token 调 People API
    userInfo := getGoogleUserInfo(req.AccessToken)
    uid = userInfo.ID
} else if req.OpenID != "" {
    // 优先级 3:HBuilderX 简化模式(⭐ 新增,前端用这个)
    uid = req.OpenID
    email = ""   // 拿不到
    name = ""    // 拿不到
} else {
    return Error("GOOGLE_TOKEN_INVALID")
}
```

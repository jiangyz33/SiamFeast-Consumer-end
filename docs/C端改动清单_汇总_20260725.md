#### 接口

**发码** `POST /api/v1/change-phone/send-sms`
```json
{ "type": "old" | "new", "phone_number": "+66812345678" }
```

**换绑** `POST /api/v1/change-phone`
```json
{
  "old_phone": "+66812345678",
  "old_code": "123456",
  "new_phone": "+66899999999",
  "new_code": "654321"
}
```

#### 关键错误码

| code | 文案 |
|---|---|
| `OLD_PHONE_MISMATCH` | 旧手机号与当前账号绑定不符 |
| `NEW_PHONE_SAME_AS_OLD` | 新手机号不能与旧手机号相同 |
| `OLD_CODE_INVALID` | 旧手机号验证码错误或已失效 |
| `NEW_CODE_INVALID` | 新手机号验证码错误或已失效 |
| `PHONE_ALREADY_BOUND` | 该手机号已被其他账号使用 |
| `PHONE_CHANGE_LIMIT` | 本月已更改过手机号,每月只能更改一次 |

#### UI 流程

```

│  当前绑定:+66812****78       │
│                              │
│  [步骤 1] 验证旧号            │
│  [+66812345678]  [获取验证码] │
│  [______________]            │
```

#### 涉及文件

| `pages.json` | 注册路由 | 0.1h |
| `i18n/index.js` | 兑换文案 | 0.3h |

#### 接口

**兑换** `POST /api/v1/coins/convert-points`:
```json
// 请求
{ "coins_to_spend": 100 }

// 响应
{
  "coins_spent": 100,
  "points_received": 10,
  "coin_balance_after": 50,
  "point_balance_after": 120
}
```

**计算公式**:`points = floor(coins_to_spend / coins_per_point)`,默认 10:1。

**错误码**:
- `INVALID_AMOUNT` → 最少兑换 N 金币
- `INSUFFICIENT_COINS` → 金币余额不足
- `EXCHANGE_DISABLED` → 功能未启用
- `DAILY_LIMIT_EXCEEDED` → 今日已达上限

#### UI 要点

```

│ 兑换比例:10 金币 = 1 积分│
│ 最少兑换:10 金币        │
│                          │
│ ┌──────────────────┐    │
│ │ 输入金币数        │    │
│ └──────────────────┘    │
```

### 改动 5:生日弹窗 + 领取

#### 涉及文件

| 文件 | 改动 | 工时 |
|---|---|---|
| **新建** `components/birthday-modal.vue` | 生日弹窗(动画 + 领取) | 2h |
| `App.vue` | 启动时调 `/birthday-status`,有就弹窗 | 0.5h |
| `api/services/member.js` | `getBirthdayStatus()` + `claimBirthday()` | 0.3h |
| `i18n/index.js` | 生日文案 | 0.5h |

#### 接口

**查询** `GET /api/v1/birthday-status`:
```json
{
  "is_birthday_today": true,
  "birthday": "1990-07-24",
  "claimable": true,
  "reward_type": "COIN",        // COIN / POINT / COUPON
  "reward_amount": 100,
  "already_claimed": false,
  "reason": ""
}
```

**领取** `POST /api/v1/birthday/claim`:
```json
{ "reward_type": "COIN", "reward_amount": 100, "grant_id": 12345, "coin_balance_after": 250 }
```

**错误码**:
- `not_birthday_today` → 今天不是您的生日
- `already_claimed` → 已领取过今年的生日奖励
- `disabled` → 生日奖励暂未开启
- `no_birthday` → 请先设置生日

#### UI 流程

```
1. App.vue onLaunch → 调 GET /birthday-status
2. 如果 claimable=true → 弹生日弹窗
3. 弹窗显示:🎂 生日快乐 + 奖励内容
4. 点"立即领取" → POST /birthday/claim
5. 成功 → 显示结果 + 关闭弹窗
6. 失败 → 按 reason / code 显示文案
```

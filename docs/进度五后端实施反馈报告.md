### 2. `GET /coupons/available` 始终返回空

- **状态**：已修复
- **改动文件**：
  - `app/api/v1/endpoints/coupons.py` — `order_amount or 0` → `order_amount`
  - `app/services/campaign_service.py` — `if order_amount < min_order_amount` → `if order_amount is not None and order_amount < min_order_amount`
- **根因**：endpoint 将 `None` 转为 `0`，导致所有 `min_order_amount > 0` 的券被过滤
- **修复方案**：`order_amount` 为 `None`（未传入）时跳过最低消费金额检查，返回所有有效 UNUSED 券
- **接口验证**：

```
GET /coupons/available                     → total=3 ✅
GET /coupons/available?order_amount=100    → total=3 ✅
```

### 4.3 `GET /products/new` 不传 `store_id` 返回 500

- **状态**：已修复
- **改动文件**：`app/schemas/products.py`
- **根因**：`ProductResponse.store_id: int`（必填），但全局菜品 `store_id` 为 `None`，Pydantic 验证失败
- **修复**：`store_id: int` → `store_id: int | None`
- **接口验证**：

```
GET /products/new?limit=4        → code=0, total=3 ✅
GET /products/new?store_id=1     → code=0 ✅
```

## 三、Campaign 门店隔离

### 问题 1：`admin_list_campaigns` 不自动按 staff.store_id 过滤

- **状态**：已修复
- **改动文件**：`app/api/v1/endpoints/campaigns.py` — `admin_list_campaigns`
- **方案**：

```python
if store_id is None and staff.role != "HQ_ADMIN" and staff.store_id:
    store_id = staff.store_id
```

- STORE_MANAGER 不传 `store_id` 时自动注入 `staff.store_id`
- HQ_ADMIN 不受影响，仍可看全部

---

### 问题 2：`admin_create_campaign` 不自动注入 store_id

- **状态**：已修复
- **改动文件**：`app/api/v1/endpoints/campaigns.py` — `admin_create_campaign`
- **方案**：

```python
if data_dict.get("campaign_type") not in ("DISCOUNT", "GROUP", "NEW_PRODUCT"):
    if staff.role != "HQ_ADMIN" and staff.store_id:
        if "store_id" not in data_dict or data_dict["store_id"] is None:
            data_dict["store_id"] = staff.store_id
        if "is_global" not in data_dict or data_dict["is_global"] is None:
            data_dict["is_global"] = False
```

- 专区活动（DISCOUNT/GROUP/NEW_PRODUCT）保持全局，不注入
- 非专区活动（CUSTOM/GENERAL 等）自动绑定门店 + `is_global=False`
- HQ_ADMIN 不受影响

- **接口验证**：

```
POST /campaigns/admin/campaigns (HQ_ADMIN, 不传 store_id)
→ 正常创建，HQ_ADMIN 不受自动注入影响 ✅
```
